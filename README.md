# 개발팀 그라운드 룰
## 작업룰
- 기능단위 작업 진행
- 기능 단위로 기술 문서 작성 (파일명 : 기능_이름.md)
- 진행도 확인 매교시 진행
- 깃 허브 브랜치는 기능 단위 브랜치, 같은 기능 브랜치에서 작업하게 될 경우 개별 브랜치 추가 생성
- 커밋 메세지 헤더는 대괄호[]로 작성 *예)[feat]기술구현*
- 데일리 체크인시간 때 개발한 기능 브리핑 진행
- PR은 최소 하루 한번
- 기능 구현 시작 전 팀 회의로 구조 결정
- 빌드에 들어가는 씬은 팀장만 작업하고 팀원은 개별씬에서 테스트


## AI 사용 규칙
- 코드 및 학습 보조용으로만 사용

## 코드컨벤션
- 필드명 - 프라이빗 _소문자 시작, 퍼블릭 대문자 시작 
- 함수명, 프로퍼티 - 단어단위 대문자 시작
- 주석 - public으로 열린 외부 접근 가능 함수, API는 ///주석 사용 (함수 의도, 기능, 매겨변수 설명이 작성되어야합니다) 
-- 내부 함수에도 함수 위에 한줄 주석으로 설명
- 메서드 내부 변수, 매개 변수는 소문자로 작성
